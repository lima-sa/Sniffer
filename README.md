Простой сетевой сниффер пакетов
Лёгкий сниффер сетевого трафика на Go, который показывает пакеты на всех интерфейсах
Минимальный инструмент для наблюдения за IP (IPv4/IPv6) и ARP-трафиком в реальном времени.
Полезен для обучения, быстрой отладки сети или изучения захвата пакетов.
Текущее состояние (февраль 2026): рабочий прототип с захватом на всех интерфейсах.
Возможности

Захват пакетов на всех сетевых интерфейсах одновременно (многопоточно)
Выводит основную информацию:
Время
IP источника → IP назначения
Протокол (TCP/UDP/ICMP и т.д. или ARP)
Размер пакета

Поддержка IPv4 и IPv6
Обрабатывает не-IP пакеты (отмечает как "Не-IP пакет")
Работает в promiscuous-режиме (захватывает весь видимый трафик)
